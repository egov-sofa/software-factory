# tasks

A command-line task list. Python 3.10 or newer, standard library only.

## Commands
- Test: `python -m unittest discover -s tests`
- Run: `python src/cli.py list`
- Lint: none configured

## Conventions
- Code in `src/`, tests in `tests/` (unittest).
- Plans live in `docs/plans/`, named `YYYY-MM-DD-<feature>.md`.
